ShippingAddressFlag

integer

Optional

This Flag is getting used differently for Regular Secondary and Virtual Cards.
For Regular Secondary Cards:
It determines the shipping address for the new card:
Valid Values:
0 = Ship to Existing Address: The card will be shipped to the existing address on file.
1 = Ship to Alternate Address: The card will be shipped to a different, specified address.
2 = Ship to Primary Cardholder's Existing Address: Applicable only for Authorized Users or Secondary Cards, the card will be shipped to the Primary Cardholder's address.
Example:If the value is set to "0," the card will be shipped to the existing address on file.
For Virtual Cards:
This flag determines whether the Virtual Card should be created with the Primary Cardholder's information or new information captured during the creation process:
Valid Values:
0 = Other: The Virtual Card will be created with new information.
1 = Same as Primary Cardholder: The Virtual Card will be created with the Primary Cardholder's information.
