LoyaltyTxnParameters

Group of Loyalty transactions parameters

Amount

decimal

The fixed number of points that are earned each time the corresponding transaction is posted against a loyalty participating amount.
Valid Values: 0-9
Format:XXX.XX
Example: 200.00
Condition: This field is only valid if the Calculation Method field is set to Use Amount.

Percent

decimal

The percent of the loyalty transaction.
Format: XXX
Example: 100
Condition: This field is only valid if the Calculation Method field is set to Use Percent.

RoundingUnit

decimal

When Rounding Method is set a value other than None, this field is used to indicate the number of decimal places that is acknowledged for the points.
Valid Values: 0-9
Format :XX.XX
Example: 0.00

CalculationMethod

string

The method used to calculate the loyalty transaction.
Valid Values: 0-9, A-Z
Use Amount - Use the value in the Amount field
Use Percent - Use the values in the Percent, Rounding Method and Rounding Unit fields.
Use Tiers - Use the values in the Transaction Tiers group.

TransactionTiers

Defines point calculations based on tiered values.
The first tier is the top end of the value range and each additional tier limit takes its beginning value from the ending value of the previous tier.
The corresponding tier amount provides the loyalty points for that transaction amount.
The initial tier begins at 0 and there are 10 tiers.
Fields of this group are only valid if the Calculation Method field is set to Use Tiers.
