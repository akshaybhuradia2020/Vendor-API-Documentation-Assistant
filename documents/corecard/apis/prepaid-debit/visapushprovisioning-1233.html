VISAPUSHProvisioning

Action: POST

Endpoint: /api/VISAPUSHProvisioning

Use this API to generate encrypted payload for Push provisioning of a Visa Card details in the Payment APP(Google pay, Samsung pay etc.).

string

clientWalletAccountID

string

Mandatory

Client provided consumer ID that identifies the wallet account holder entity.

should have the same value.
Format: String, alphabetic, numeric, hyphens ( - ), and underscores ( _ ), spaces are not allowed.

Allowable Values:

24

intent

integer

Mandatory

The intent of the encryptor, which specifies what the encryptor of the data trying to do.
Valid Values: PUSH_PROV_MOBILE=0, (Push the PAN data to a Token Requestor to
provision a token for the card holder on a specific device for a specific wallet/account)
PUSH_PROV_ONFILE=1 (Push the PAN data to a Card On File merchant/Token Requestor to provision a token for the cardholder)
Example : 0

Response fields detail
Fields Description

Message

string

Status

boolean

Returns result of API processing.
If any error is found then value will be 'false' else 'true'.

ErrorCode

string

Returns Error Code in case of Error.

ResponseData

This is group of below data elements.

ProxyNumber

string

Proxy Number of the cardholder
Valid values:0-9
Example:1005

string

Encrypted Payload calculated over a the field values of Input.
