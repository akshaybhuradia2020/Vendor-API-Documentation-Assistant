Rejected Transactions

<p>A transaction that is &nbsp;rejected in ACH processing, limit checks, or due to an invalid card number (e.g., card does not exist in the system) is called a rejected transaction. Rejected transactions can be reviewed and updated with valid details. If rejected transactions need to be posted to targeted card accounts, then a transaction batch is created and submitted.</p>
