GetCardDetails

Action: POST

Endpoint: /api/CoreCredit/CardManagement/GetCardDetails

This API is used to retrieve card embossing details by providing the account\admin number and card sequence number in input. Details like card limit, expiry date, manual status, card type, etc. are returned..
