GetWelcomePackageURL

Action: POST

Endpoint: /api/CoreCredit/AccountManagement/GetWelcomePackageURL

The purpose of this API is to fetch the welcome package URL for the account holder.

Request fields detail
Fields Description

Source

string

Mandatory

Source of API Consumer
For external system expected sources will be WEB.

Allowable Values:

50

IPAddress

Optional

IP Address of Client / Application Hosting Server
Example: 10.206.0.204

Allowable Values:

15

string

Optional

Place Holder for Future Use.
Values are:
1 : MM/dd/yyyy HH:MM:SS (Default)
2 : MM/dd/yy HH:MM:SS
3 : dd/MM/yyyy HH:MM:SS

25

Optional

Currency Code

10
